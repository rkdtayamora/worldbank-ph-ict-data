# ICT Connectivity & Trade Profile for 21st Century
A project using World Bank data to examine how the Philippines' digital connectivity relates to its ICT trade profile. To be built using Excel, SQL, Power BI.

>  **Status**: In Progress. Data audit phase is complete.

## Business Question: 
> As the Philippines expanded its digital connectivity in the 21st century, how has this affected its ICT trade profile?
